# ינשופים · שנה א׳ סמסטר א׳

אתר סטטי לצפייה בסרטוני סיכום השיעורים המונפשים, לפי סמסטר וקורס.

- `index.html` — הממשק (מותאם לטלפון, RTL).
- `data.js` — רשימת הסמסטרים, הקורסים והשיעורים. כדי להוסיף שיעור: מעלים את קבצי הווידאו ל-`v/` ומוסיפים רשומה כאן.
- **מה עולה לאתר:** רק סרטונים סופיים של קורסים בתואר — עם הקריינות המסונכרנת. לא דוגמאות, טיוטות או סרטונים שקטים.
- `v/` — קובץ MP4 רציף אחד לכל שיעור (720p) ותמונת תצוגה. הפרקים מוגדרים ב-`data.js` כנקודות קפיצה בתוך הסרטון (`chapters:[[שם, שנייה]]`).

כל push ל-`main` מתפרסם אוטומטית ב-Vercel.
